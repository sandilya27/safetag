# SAFETAG — Website Redesign & Development

Comprehensive digital platform redesign and development for **SAFETAG**, delivering a modern, high-performance, and secure web presence for industrial testing, inspection, calibration, and technical services.

---

## 📌 Project Overview

This repository houses the design specifications, branding assets, and codebase for the SAFETAG website redevelopment project.

### Key Objectives
- **Modern Digital Presence**: Elevate SAFETAG's industrial inspection, testing, and calibration services.
- **Service Discovery & Inquiries**: Streamlined inquiry management and quotation requests.
- **Performance & SEO**: High-performance Core Web Vitals optimization and search engine visibility.
- **Enterprise Security & Reliability**: Robust, scalable architecture with production monitoring.

---

## 🛠 Proposed Technology Stack

- **Frontend**: Next.js 16 (App Router), TypeScript, Tailwind CSS, shadcn/ui
- **Backend**: Node.js, Express.js
- **Database & ORM**: PostgreSQL, Drizzle ORM
- **Content Management**: Strapi Headless CMS
- **Deployment & Infra**: Cloud hosting with automated CI/CD
